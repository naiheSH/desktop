# 中文本地化范围

本次以官方 `release-3.6.7` 为基线检查。目标是保留官方功能、界面结构和 Git 行为，仅修改本地化所需的显示文本与格式，以及中文版必要的发布和更新适配。

## 已检查的界面

- 欢迎和登录、新建/添加/克隆/发布仓库。
- 更改与历史面板、提交摘要/描述、修订提交、提交选项、仓库规则提示。
- 差异视图、行号与区块控件、文件筛选、储藏、分支和工作区操作。
- 拉取请求预览、文件列表、合并比较与冲突处理。
- 设置的所有标签页，包含 Git、外观、通知、无障碍和 Copilot。
- Copilot 模型选择、自定义提供商、模型校验、用量和点数、手动/自动解决冲突。
- 主菜单、上下文菜单、占位文本、悬浮提示、读屏文本和常见用户错误。

本次补齐了六百余处英文文本片段，包含模板字符串和读屏文本。该数量不是翻译覆盖率；源码静态扫描不能证明所有运行场景均已覆盖。动态拼接的句子也需要人工检查中文语序。

## 与官方保持一致

- 移除继承的 Difftastic 接入、差异模型扩展、行内差异算法和相应样式，恢复官方差异渲染实现。
- 清理与这些增强相关的未使用工具和专属测试。
- 不新增本地化运行框架，也不重构官方业务流程。
- Git 术语以官方 `git/git` 的 `po/zh_CN.po` 词表为主要依据。储藏（stash）与暂存（stage）、还原（revert）与重置（reset）分别表达。
- 命令参数、协议字段、状态键、CSS 类名、模型标识及 Copilot 提示词保留原样。通过语法树对比复查本轮修改中的技术标识，避免把代码值当作界面文字翻译。

## 有意保留的英文

产品/编辑器/模型名，文件名和路径，分支名，用户输入和提交内容，协议及单位，第三方模型分类/服务响应，以及用于排查问题的原始 Git 输出、开发日志和内部断言。英文法律原文保留，已有中文说明仅作参考。

这些内容不应为了“纯中文”而替换。新增官方功能、罕见错误或第三方返回内容仍可能出现尚未覆盖的英文，不以测试通过宣称绝对完整。

## 验证

本机 macOS 的类型、格式与静态检查、完整单元测试及真实 Electron 冒烟测试均用于回归。Windows 菜单使用 Windows 平台标志额外检查快捷键冲突；完整 Windows 安装、签名和升级仍由发布 CI 验证。

维护时应先合并官方补丁，再逐项检查新增的界面文本及其测试，保留已有英文技术标识和数据。不要用全局替换英文单词的方式处理源码。
